【導入方法】
※2015/6/20以前に本スクリプトを導入した人は一度「OT_skill」フォルダを削除してください。
「OT_skill」をPluginフォルダの中に入れてください。

スキル発動条件追加との併用推奨。
（特にステータス依存攻撃は同種スキルの発動順チェック(DuplicateSkill.js)を入れてる事を想定）

アーマーブレイク(skill-BreakAttack.js)とステータス依存攻撃(skill-StatusAttack.js)は仕様上、
別のカスタムスクリプトと競合を起こしやすいため(総合Cal等)、別カスタムスクリプトを併用する場合は
「OT_skill」のフォルダ名を「0OT_skill」に変更して先に読み込むようにするか
記述を別のスクリプトにマージする、
あるいは使用しない場合は該当スクリプトを外してください。

-----------------------------------------------------------------------------------------
【概要】
導入する事により下記のスキルを使用できるようになります。

・発動時に必ずクリティカル攻撃
・防御力無視攻撃
・ランダム複数回攻撃
・被ダメージ吸収
・戦闘続行
・攻撃ヒット時に相手のラウンド数を減らす
・スキル所有者の攻撃力と攻撃対象の防御力を特定ステータスに依存させる

-----------------------------------------------------------------------------------------
【使用方法】
■ファイル名：skill-BreakAttack.js
・スキル[アーマーブレイク](月光っぽいもの)
使用方法：カスタムスキルのキーワードに[OT_BreakAttack]と入力。

このスキルが発動時すると敵の防御力を無視した攻撃になります。
防御力を何%無視するか設定したい場合はカスタムパラメータの設定を行い、
パラメータを設定しなかった場合は相手の防御力は完全無視になります。

・渡せるカスタムパラメータ
{
  BreakPercent:(数値)	//相手の防御力を何%無視するか設定
}

例：
BreakPercent:60と設定すれば相手の防御力の60%無視します。

■ファイル名：skill-Critical.js
・スキル[クリティカルアタック]
使用方法：カスタムスキルのキーワードに[OT_Critical]と入力。

このスキルが発動時すると攻撃がクリティカルになります。

「OT_ExtraConfigSkill」フォルダと一緒に入れて
発動率を100%、カスタムパラメータにて
{
  EC_NowHP:'0-50%'
}
と指定すれば、FEのスキル「怒り」(HP50%以下でクリティカル攻撃)を再現できます。


ーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーー
■ファイル名：skill-BoisterousDance.js
・スキル[乱舞]
使用方法：カスタムスキルのキーワードに[OT_BoisterousDance]と入力。

スキルが発動時すると複数回のランダム攻撃になります。
このスキルの所持時は与えられるダメージが軽減されます。
(カスタムパラメータで発動時のみダメージが軽減にする事も可能)

・渡せるカスタムパラメータ
{
    DamageRate     :(数値)	//何%ダメージになるか設定
  , MaxAttackCount :(数値)	//最大何回攻撃するか設定できます
  , MinAttackCount :(数値)	//スキル発動時最低でもこの設定値分の攻撃は行います
  , isRateChange   :(数値)	//0でスキルを所持しているだけでダメージレート変更、1でスキル発動時のみダメージレート変更となります。
  , isNoReattack   :(数値)	//1-239氏の統合CalAのnoreattackの影響を受けるか設定、1で受ける、0で受けない
}

例：
DamageRate       : 30
MinAttackCount   : 3
MinAttackCount   : 6
isRateChange     : 1

スキル発動後、最低でも3回は攻撃を行い、最大で6回攻撃を行います。
また、与えるダメージはスキル発動時のみ30%になります。

※
DamageRateが未設定なら50になります。
MaxAttackCountが未設定なら5になります。
MinAttackCountが未設定なら2になります。
isRateChangeが未設定なら0になります。
isNoReattackは未設定なら1になります。


ーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーー
■ファイル名：skill-AbsorptionDamage.js
・スキル「被ダメージ吸収」
使用方法：カスタムスキルのキーワードに[OT_AbsorptionDamage]と入力。

スキル発動時に相手から受けるダメージを吸収してHPが回復します。

・渡せるカスタムパラメータ
{
  AbsorptionPercent:(数値)	//ダメージの何%を吸収するか設定
}

AbsorptionPercentが未設定なら100になります。


ーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーー
■ファイル名：skill-Assault.js
・スキル「戦闘続行」
使用方法：カスタムスキルのキーワードに[OT_Assault]と入力。

スキルが発動すると戦闘を続行します。
ただし、スキル所持者が一方的に攻撃される状況では発動しません。
(スキル所持者が一方的に攻撃できる状況なら発動可、カスパラで発動不可に設定可能)

・渡せるカスタムパラメータ
{
    AS_Max:(数値)			//発動回数上限(未指定時は50)
  , AS_OneSide:(論理値)		//一方的に攻撃できる状況で発動するか(未指定時はtrue)
  , AS_AbortCheck:(論理値)	//不死身ユニットが相手の場合、不死身ユニットが瀕死になった時に発動を抑制する(未指定時はfalse)
}

AS_Max未指定時のデフォルト値はskill-Assault.jsのAS_MaxActivateで定義されています。

AS_AbortCheckについてtrueにした場合、イベントの設定で不死身状態になったキャラに対して
スキルやクリティカルでHPが0になる攻撃をした場合に発生する強制回避の実行時、
通常攻撃のダメージ量がHPを上回った時に発動しないようになります。
発動者が一方的に攻撃されて不利になる状況を緩和します。

ーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーー
■ファイル名：skill-Cancel.js
・スキル「キャンセル+」
使用方法：カスタムスキルのキーワードに[OT_Cancel]と入力。

スキル発動時に相手のラウンド数を減らします。

カスタムパラメータ
{
  CancelCount:(数値)	//何ラウンドを減らすか設定
}

CancelCountが未設定ならラウンドを全て減らします。

■ファイル名：skill-StatusAttack.js
・スキル「ステータス依存攻撃」
使用方法：カスタムスキルのキーワードに[OT_StatusAttack]と入力。

スキル所有者の攻撃力と攻撃対象の防御力をカスタムパラメータで指定した
ステータスに依存したものになります。

基本的には武器にスキルを設定、
ユニットに持たせる場合はコマンドスキル化する事を推奨。
ディスガイアの弓みたいに(力/2＋技/2)を攻撃力にする事もできます。

またスキル発動条件追加を導入している時にコマンドスキル化も可能。
非コマンドスキルのものとコマンドスキル化したものを両方所持している場合は
通常は非コマンドスキルのスキル、コマンドスキル発動時はコマンドスキル側のスキルが発動します。

カスタムパラメータ(各値省略可)
{
    SA_AttackValue :
    {   
        LV:(数値、小数点・マイナス指定可能)
      , HP:(数値、小数点・マイナス指定可能) // 現在値×カスパラ値になります
      , EP:(数値、小数点・マイナス指定可能) // 現在値×カスパラ値になります、MP(EP)&必殺ゲージ(FP)追加プラグイン導入時のみ
      , FP:(数値、小数点・マイナス指定可能) // 現在値×カスパラ値になります、MP(EP)&必殺ゲージ(FP)追加プラグイン導入時のみ
      , POW:(数値、小数点・マイナス指定可能)
      , MAG:(数値、小数点・マイナス指定可能)
      , SKI:(数値、小数点・マイナス指定可能)
      , SPD:(数値、小数点・マイナス指定可能)
      , LUK:(数値、小数点・マイナス指定可能)
      , DEF:(数値、小数点・マイナス指定可能)
      , MDF:(数値、小数点・マイナス指定可能)
      , MOV:(数値、小数点・マイナス指定可能)
      , WLV:(数値、小数点・マイナス指定可能)
      , BLD:(数値、小数点・マイナス指定可能)
      , WPN:(数値、小数点・マイナス指定可能) //武器の攻撃力を補正、未指定時のデフォルト1.0
    }
    ,
    SA_DefenceValue :
    {   
        LV:(数値、小数点・マイナス指定可能)
      , HP:(数値、小数点・マイナス指定可能) // 現在値×カスパラ値になります
      , EP:(数値、小数点・マイナス指定可能) // 現在値×カスパラ値になります、MP(EP)&必殺ゲージ(FP)追加プラグイン導入時のみ
      , FP:(数値、小数点・マイナス指定可能) // 現在値×カスパラ値になります、MP(EP)&必殺ゲージ(FP)追加プラグイン導入時のみ
      , POW:(数値、小数点・マイナス指定可能)
      , MAG:(数値、小数点・マイナス指定可能)
      , SKI:(数値、小数点・マイナス指定可能)
      , SPD:(数値、小数点・マイナス指定可能)
      , LUK:(数値、小数点・マイナス指定可能)
      , DEF:(数値、小数点・マイナス指定可能)
      , MDF:(数値、小数点・マイナス指定可能)
      , MOV:(数値、小数点・マイナス指定可能)
      , WLV:(数値、小数点・マイナス指定可能)
      , BLD:(数値、小数点・マイナス指定可能)
    }
}

SA_AttackValueを省略時は攻撃側の攻撃力は通常通り、
武器+(武器が物理なら力、武器が魔法なら魔力)となり
SA_DefenceValueを省略時は攻撃対象の防御力は通常通り、
攻撃側の武器が物理なら防御力、武器が魔法なら魔防力となります。

例1：
{
    SA_AttackValue :{ POW:0.5, SKI:0.5 }
}

攻撃時に(力*0.5)+(技*0.5)+武器威力が攻撃力になります。

例2：
{
     EC_Command           : 'ATTACK'
   , EC_CommandDuration   : 0
   , SA_AttackValue       : { POW:1.5, WPN:1.5 }
   , SA_DefenceValue      : { LUK:2.0 }
}

攻撃型のコマンドスキル。
コマンドスキルでの攻撃時に(力*1.5)+(武器威力*1.5)が攻撃力になります。
スキル保有者の攻撃対象の防御力は幸運*2.0になります。

例3：
{
     EC_Command           : 'WAIT'
   , EC_CommandDuration   : 3
   , SA_AttackValue       : { MAG:3.0, WPN:0.0 }
   , SA_DefenceValue      : { MAG:1.0 }
}

待機型のコマンドスキル
コマンドスキル実行後、3ターン発動者の(魔力*3.0)が攻撃力になります。
発動中は攻撃対象の防御力は魔力*1.0になります。


例4：
{
     SA_AttackValue  : { DEF:1.0, WPN:0.0 }
   , SA_DefenceValue : { POW:-1.0, DEF:1.0 }
}

攻撃時に(防御力*1.0)が攻撃力になります。
スキル保有者の攻撃対象の防御力は(防御力*1.0)-力になります。
