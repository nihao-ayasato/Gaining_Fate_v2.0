★カスタムパラメータなど説明（詳細は各スクリプトを参照願います。）
	・ユニット
		{swd: 71} 剣熟練度の初期値が71。武器タイプによって変わります(槍ならlnc,斧ならaxeなど) 初期値は1
		{swdGrowthBonus: 80} 剣熟練度の成長値が80%。あまり設定する意味はないかも？
	
	・クラス
		{swd: 121} このクラスに属している場合に、剣熟練度が+121。武器タイプによって変わります。初期値は0
		{swdMax: 181} このクラスに属している場合、剣熟練度の上限が181になります。初期値は251(レベルS)。
	
	・アイテム（武器、杖）
		{wlv: 71} 武器レベルが71。ユニットの対応する武器の熟練度がこれ以上なら装備可能。初期値は1
		{wexp: 2} 武器経験値が2。戦闘(杖使用)後に、この値だけ熟練度が上がります。初期値は1
		{wtype: 0}(★設定必須) 武器タイプが0(剣)。全ての武器に、武器タイプに応じた値を設定して下さい。
		                       デフォルトでは(0(剣),1(槍),2(斧),3(弓),4(魔法)となっています。
		                       詳しくはedit_weapontype-case参照。
		武器　{swd: 71} この武器を装備している場合、剣熟練度+71。武器タイプによって変わります。初期値は0
		道具　{swd: 71} この道具を所持している場合、剣熟練度+71（同一種類の道具を複数所持しても効果は重複しません）
		ドーピングアイテム　{swdDoping: 71} このドーピングアイテムを使用すると、ユニットの剣熟練度に+71されます。
		                       詳しくはcustom-unit-jyukurendo.jsのコメントを参照。
	

★熟練度、武器レベルのランクについて
	FEのように、武器熟練度、武器レベルはS,A～Eの段階で表示しています。
	内部的には1～251の数字で管理されているものを、以下のように変換して表示しています。
	
		1～30    : E
		31～70   : D
		71～120  : C
		121～180 : B
		181～250 : A
		251～    : S
		
	なので、武器レベルをランクDにしたいなら、Dの最低値である31をカスタムパラメータとして設定します。
	
		例：  {wlv: 31} ← これが武器ランクDという意味
			  {wlv: 190} ← この場合見た目の武器ランクはAになるが、
			                熟練度がA(181)になったばかりのユニットでは装備出来ない、という現象が起こる
	
	この定義を変更したい場合、そもそも数字のまま表示したいという場合は、edit_weapontype-caseを編集してください。
