/*

---------------------------------------------
導入の仕方
---------------------------------------------

１．zipファイルを展開します。
　　（srpg studio用_試作スクリプト～.zipの上で右クリック→全て展開を選択してください）

２．１で展開したフォルダの中に「srpg studio用_試作スクリプト」というフォルダがあるので、
　　これをSRPG STUDIOのプロジェクトのpluginフォルダにコピーして下さい。
　　※SRPG STUDIOのプロジェクトを新規に作って保存すると、デスクトップにproject1のようなフォルダがある筈です。

３．pluginフォルダにコピーした「srpg studio用_試作スクリプト」のフォルダの中に
　　「$JukurendoBar」というフォルダがあるので、
　　これをMaterialフォルダにコピーし、フォルダ名を「JukurendoBar」にしてください（先頭の$を消すだけです）

４．この状態でSRPG STUDIOのプロジェクトを立ち上げ、マップテストを実行してください。
　　テストマップ表示後、ユニットのステータス画面を表示して→を押すとステータスの下半分が切り替わり
　　$サンプル画像.jpgのような画面が表示されていれば導入成功です。
　　（もう一度→を押すと元の表示になります）

※このままでもとりあえず動作はしますが、実際に熟練度が上がって使用可能な武器（杖）が増えるようにするには、
　武器、杖にカスタムパラメータを設定する必要があります。




---------------------------------------------
武器へのカスタムパラメータの設定
---------------------------------------------

※このプラグインがデフォルトで対応している武器は、剣、槍、斧、弓、魔法の5種類です。
　（種類を増やしたい場合、改造が必要となります）

　武器の場合、以下のようなカスタムパラメータを設定しておく必要があります。
　　{wlv:1, wexp: 1, wtype: 0}

　　　wlv　:　その武器を使用する為に必要な熟練度です。
　　　　　　1が最低（Eランク）で、31がDランク、71がCランク、121がBランク、181がAランク、251がSランクとなります。

　　　wexp :　その武器を使用するごとに増えていく熟練度です。
　　　　　　　0だと幾ら使用しても武器レベルが上昇しません。1以上の値を入れておくことをお勧めします。

　　　wtype:　対応する武器です。
　　　　　　　0だと剣、1だと槍、2だと斧、3だと弓、4だと魔法となります。


　　※剣の場合、以下のような感じでカスタムパラメータを設定しておく必要があります。
　　　{wlv:1, wexp: 1, wtype: 0}




---------------------------------------------
杖へのカスタムパラメータの設定
---------------------------------------------

　杖の場合、以下のようなカスタムパラメータを設定しておく必要があります。
　　{wlv:1, wexp: 1}

　　　wlv　:　その杖を使用する為に必要な熟練度です。
　　　　　　1が最低（Eランク）で、31がDランク、71がCランク、121がBランク、181がAランク、251がSランクとなります。

　　　wexp :　その杖を使用するごとに増えていく熟練度です。
　　　　　　　0だと幾ら使用しても武器レベルが上昇しません。1以上の値を入れておくことをお勧めします。




---------------------------------------------
クラスへのカスタムパラメータの設定
---------------------------------------------
　※必須ではありません。

　剣士は最初から剣Dで、ランクBまで上昇するようにしたい、というようにクラスによって武器の使用可能ランクを決めたい場合
　以下のようなカスタムパラメータをクラスに設定しておく必要があります。
　　{swd: 31, swdMax: 121}

　　　swd　 :　剣の熟練度への補正値です。
　　　　　　31だとDランク、71だとCランク、121だとBランク、181だとAランク、251だとSランクへと補正します。

　　　swdMax:　剣の熟練度最大値です。
　　　　　　31だとDランク、71だとCランク、121だとBランク、181だとAランクまでしかランクが上昇しなくなります。

　　　※槍ならlncとlncMax、斧ならaxeとaxeMax、弓ならarwとarwMax、魔法ならmgcとmgcMaxに差し替えて記述して下さい


　杖の場合は、クラスに以下のような感じで設定して下さい
　　{wand: 31, wandMax:121}




---------------------------------------------
ユニットへのカスタムパラメータの設定
---------------------------------------------
　※必須ではありません。

　主人公は傭兵だけど最初から剣D、普通の傭兵は剣E、というようにユニットごとに武器の使用可能ランクを変えたい場合
　以下のようなカスタムパラメータをユニットに設定しておく必要があります。
　　{swd: 31, swdGrowthBonus: 10}

　（レベルアップで成長させない場合は以下のように記述して下さい）
　　{swd: 31}

　　　swd　 :　剣の熟練度への補正値です。
　　　　　　31だとDランク、71だとCランク、121だとBランク、181だとAランク、251だとSランクへと補正します。

　　　swdGrowthBonus:　剣熟練度の成長率です。
　　　　　　レベルアップ時に数値%の確率で1上昇します

　　　※槍ならlncとlncGrowthBonus、斧ならaxeとaxeGrowthBonus、弓ならarwとarwGrowthBonus、魔法ならmgcとmgcGrowthBonusに差し替えて記述して下さい


　杖の場合は、クラスに以下のような感じで設定して下さい
　　{wand: 31, wandGrowthBonus:10}

　（レベルアップで成長させない場合は以下のように記述して下さい）
　　　{wand: 31}




---------------------------------------------
熟練度の値とランクの対応について
---------------------------------------------
	FEのように、武器熟練度、武器レベルはS,A～Eの段階で表示しています。
	内部的には1～251の数字で管理されているものを、以下のように変換して表示しています。
	
		1～30    : E
		31～70   : D
		71～120  : C
		121～180 : B
		181～250 : A
		251～    : S
		
	なので、武器レベルをランクDにしたいなら、Dの最低値である31をカスタムパラメータとして設定します。
	
		例：  {wlv: 31} ← これが武器ランクDという意味
			  {wlv: 190} ← この場合見た目の武器ランクはAになるが、
			                熟練度がA(181)になったばかりのユニットでは装備出来ない、という現象が起こる
	
	この定義を変更したい場合、そもそも数字のまま表示したいという場合は、edit_weapontype-caseを編集してください。


*/
